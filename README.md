# Simulador-SO---Gesti-n-de-Procesos-y-Memoria
Desarrollar un programa que realice Gestión de procesos y Gestión de memoria (emulando a un sistema operativo), de forma transaccional (mostrando cada paso/estado que se da en el sistema cuando realiza Gestión de procesos y Gestión de memoria). Priorizar INTERRUPCIONES como las señales para que se ejecuten los algoritmos de gestión.
