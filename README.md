# Simulador de SO: Gestión de Procesos y Memoria

Simulador de un sistema operativo que emula la gestión de procesos y de memoria
de forma transaccional (muestra cada paso/estado), con interrupciones como
mecanismo que dispara los algoritmos de gestión.

## Cómo ejecutar
1. Crear y activar el entorno virtual:
   python -m venv .venv
   .venv\Scripts\Activate.ps1
2. Instalar dependencias:
   pip install -r requirements.txt
3. Ejecutar:
   python src/main.py
